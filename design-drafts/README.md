# Design drafts

Borradores de sistemas de diseño para **Forja** — temas candidatos, aún **no oficiales**.

> La dirección **oficial** vive en [`design-system/MASTER.md`](../design-system/MASTER.md).
> Estos son experimentos de arte, cada uno con su `*.md` y (idealmente) su showcase HTML, para
> poder comparar lenguajes sin pisar el sistema vigente.

| Tema | Doc | Origen de referencia | Showcase |
|---|---|---|---|
| **Molar** | [molar.md](molar.md) | Dashboard SaaS "Molar AI" (agente IA) | [app atleta](../fragua-redesign-molar-app.html) _(backoffice pendiente)_ |
| **Aurora** | [aurora.md](aurora.md) | Dashboard "Tasklyn" (soft glass) | [app atleta](../fragua-redesign-aurora.html) |

## Cómo añadir un tema

1. Escribe `design-drafts/<tema>.md` con la misma estructura (Principios · Color · Tipografía ·
   Espaciado/radios/sombras · Componentes · Movimiento · Anti-slop · Mapa del showcase).
2. Crea `fragua-redesign-<tema>.html` en la raíz, basado en ese doc.
3. Agrega la fila a esta tabla.
